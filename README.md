## Overview

This repository contains a complete experimental pipeline for binary classification of **antimicrobial peptides (AMPs)** using protein representations generated by **ProtFlash**.

The project evaluates how different sequence aggregation strategies affect classification performance:

- **Mean Pooling**
- **Mean Pooling + AAontology**
- **Gated Pooling**
- **Gated Pooling + AAontology**

Each strategy is tested with three classifier families:

- **MLP**
- **1D-CNN**
- **BiLSTM**

The final comparison is performed on an external test set, followed by an explainability analysis of the best-performing strategy.

---

## Project Highlights

- Uses **ProtFlash residue-level embeddings** with dimensionality `768`.
- Uses a global/contextual embedding `G` of dimensionality `768`.
- Supports masked sequence processing with binary masks `M`.
- Incorporates **AAontology** amino-acid property profiles with shape `(21, 8)`.
- Compares **12 training configurations**:
  - 4 pooling/enrichment strategies
  - 3 neural architectures
- Performs external validation on a held-out test set of **15,685 samples**.
- Evaluates models using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
  - MCC
  - ROC-AUC
  - PR-AUC
  - Confusion matrices
- Includes an explainability stage using:
  - Integrated Gradients
  - KernelSHAP
  - Residue-level importance analysis
  - Biological validation using the LL-37 peptide

## Dataset

The final dataset is serialized as PyTorch-compatible files.

| Split | Samples |
|---|---:|
| Train | 13,766 |
| Validation | 4,128 |
| External Test | 15,685 |

### External Test Class Distribution

| Class | Samples |
|---|---:|
| Positive | 4,914 |
| Negative | 10,771 |
| Positive/Negative Ratio | ~0.46 |

### Sequence Length

Sequences were normalized to a length range of:

```text
MIN_LEN = 10   # shorter sequences were padded up to this length
MAX_LEN = 100  # longer sequences were truncated to this length
```

### Base Tensors

For standard ProtFlash-based models, each sample contains:

| Tensor | Shape | Description |
|---|---|---|
| `X` | `(100, 768)` | ProtFlash residue-level embeddings |
| `G` | `(768,)` | Global/contextual sequence embedding |
| `M` | `(100,)` | Binary mask for valid residues |
| `seq` | string | Raw amino-acid sequence |
| `y` | scalar | Binary AMP label |

### AAontology Tensors

For AAontology-aware models, an additional per-residue ontology representation is used:

| Tensor | Shape | Description |
|---|---|---|
| `Ont` | `(100, 8)` | AAontology property profile per residue |

The AAontology amino-acid tensor has shape:

```text
(21, 8)
```

where each amino-acid category is represented by an 8-dimensional z-scored property profile.

## Modeling Strategies

The repository evaluates four main modeling strategies.

### 1. Mean Pooling

Aggregates residue-level embeddings using masked mean pooling.

```text
X + M -> MeanPooler -> E
[E, G] -> Classifier
```

### 2. Mean Pooling + AAontology

Combines ProtFlash residue embeddings with AAontology amino-acid property profiles.

```text
X + Ont + M -> AAontology pooling -> E_local
X + M -> global pooling -> E_global
[E_local, E_global] -> Classifier
```

### 3. Gated Pooling

Learns residue-level importance weights through a trainable gating mechanism.

```text
X + M -> GatedPooler -> E
[E, G] -> Classifier
```

### 4. Gated Pooling + AAontology

Combines trainable gating with AAontology property information.

```text
X + Ont + M -> AAontology gated pooling -> E
[E, G] -> Classifier
```

---

## Architectures

Each pooling strategy is evaluated with three classifier backbones.

### MLP

Fully connected classifier using:

- `Linear`
- `BatchNorm1d`
- `GELU`
- `Dropout`

### 1D-CNN

Convolutional classifier using:

- `Conv1d`
- `BatchNorm1d`
- `GELU`
- `Dropout1d`
- Max pooling
- Average pooling

### BiLSTM

Bidirectional recurrent classifier using:

- `BiLSTM`
- Packed padded sequences
- Max pooling over LSTM outputs
- Average pooling over LSTM outputs
- Fully connected classification head

## External Validation Results

The following table summarizes the best model selected from each strategy on the external test set.

| Strategy | Best Architecture | Params | Test Accuracy | Test F1 | Test MCC | Test ROC-AUC | Test PR-AUC |
|---|---|---:|---:|---:|---:|---:|---:|
| Mean Pooling | CNN_Small | 549,953 | 0.9068 | 0.8584 | 0.7911 | 0.9600 | 0.9390 |
| Mean Pooling + AAontology | BiLSTM_Small | 1,824,065 | **0.9178** | **0.8709** | **0.8108** | 0.9571 | 0.9354 |
| Gated Pooling | CNN_Large | 3,183,490 | 0.9118 | 0.8652 | 0.8014 | **0.9629** | 0.9413 |
| Gated Pooling + AAontology | MLP_Small | 1,125,442 | 0.9142 | 0.8663 | 0.8037 | 0.9600 | **0.9445** |

### Interpretation

- **Mean Pooling + AAontology + BiLSTM_Small** achieved the best external test MCC.
- It also achieved the highest test accuracy and F1-score among the compared strategies.
- **Gated Pooling + CNN_Large** achieved the highest ROC-AUC.
- **Gated Pooling + AAontology + MLP_Small** achieved the highest PR-AUC.
- The results suggest that AAontology information can improve discriminative performance, especially when combined with sequence-aware architectures such as BiLSTM.

- Importance aggregation by sequence position

## Reproducibility Notes

- A fixed random seed is used across experiments.
- Train/validation/test splits are kept separate.
- External test evaluation is performed after model selection.
- Metrics are computed using a fixed threshold of `0.5`.
- Model selection during training is based primarily on validation loss.
- Final strategy comparison is based primarily on external test MCC.

---

## Limitations

- The comparison couples pooling strategy and architecture; therefore, performance differences cannot be attributed exclusively to pooling.
- The external test set is more imbalanced than the training/validation splits.
- PR-AUC and ROC-AUC may favor different models depending on the operating point.
- Explainability results are interpretive and should be validated with domain knowledge.
- Raw sequence data and large embedding files are not included in the repository by default.
